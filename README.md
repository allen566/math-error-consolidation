# 📐 高中数学错题巩固神器

一个智能的高中数学错题分析和练习工具！

## ✨ 功能特性

- 🎯 **知识点分析**：智能提取题目涉及的知识点
- 💡 **解题思路**：提供详细的解题思路和答案
- 🔄 **举一反三**：自动生成类似题目，包含高考真题
- 📱 **手机访问**：支持手机访问，在同一WiFi下即可访问
- 📝 **LaTeX公式**：支持 LaTeX 公式输入和渲染

## 🛠️ 技术栈

- **后端**：Python 3
- **前端**：HTML + JavaScript
- **数学公式**：MathJax

## 📦 安装步骤

### 1. 克隆项目

```bash
git clone <your-repo-url>
cd <your-repo-folder>
```

### 2. 运行程序

无需额外依赖！直接运行：

```bash
python app.py
```

访问：http://localhost:5000

## 📱 手机访问

手机和电脑连接同一WiFi后，访问显示的地址，如：
```
http://192.168.1.100:5000
```

## 📂 项目结构

```
.
├── app.py                  # 主程序
├── math_analyzer.py        # 数学分析引擎
├── question_generator.py   # 题目生成器
└── templates/
    └── index.html         # 前端页面
```

## 🎯 使用说明

1. **输入题目**：在文本框中输入题目内容（支持 LaTeX）
2. **查看分析**：点击分析，自动生成知识点、解题思路
3. **巩固练习**：查看类似题目，举一反三

## 📝 示例题目

```
设a为常数。问函数f(x)=tan(ax+π/4)是否是奇函数？并说明理由。
```

支持 LaTeX 公式：$x^2$、$\frac{a}{b}$、$\sqrt{2}$
